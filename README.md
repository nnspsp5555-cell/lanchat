# LanChat Local — مشروع جديد

واجهة عربية RTL للمراسلة المحلية عبر شبكة Wi-Fi، باستخدام Node.js + Express + WebSocket.

## الميزات الموجودة في هذه النسخة
- غرف محادثة عامة حسب اسم الغرفة.
- رسائل نصية وسجل محفوظ على الخادم (آخر 2000 رسالة).
- قائمة بالمستخدمين المتصلين، والضغط على اسم مستخدم يختار المحادثة الخاصة.
- مشاركة صور وفيديو وصوت ومستندات، بحد أقصى 40MB للملف.
- اختيار لون واجهة وخلفية شخصية من صور الهاتف.
- تصميم متجاوب للهاتف مع واجهة عربية.

## تشغيل الخادم
يتطلب Node.js 18 أو أحدث، واتصالاً محلياً بين الأجهزة على نفس شبكة Wi-Fi.

```bash
npm install
npm start
```

يفتح الخادم المنفذ 3000 على كل واجهات الشبكة، ويطبع عنوان LAN في الطرفية مثل `http://192.168.1.10:3000`. افتح هذا العنوان من المتصفح على الأجهزة الأخرى المتصلة بنفس الراوتر.

## رفع المشروع إلى GitHub من الهاتف
1. أنشئ مستودعاً جديداً باسم `lanchat-new`.
2. ارفع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP وحده إذا أردت تعديل الملفات مباشرة).
3. ملاحظة: GitHub Pages لا يشغّل خادم Node.js؛ يلزم جهاز على الشبكة لتشغيل الخادم. هذا المشروع حالياً تطبيق ويب محلي وليس APK جاهزاً.

## تنبيه أمني مهم
هذه النسخة **لا تطبق تشفيراً للتطبيق أو النقل** وتستخدم `http://` و`ws://`. أي شخص يستطيع مراقبة الشبكة المحلية المناسبة قد يتمكن من الاطلاع على البيانات، والملفات محفوظة على جهاز الخادم. استخدمها للتجربة فقط ولا ترسل كلمات مرور أو بيانات حساسة. لا تفتح المنفذ على الإنترنت.

## حدود النسخة الحالية
- المحادثات الخاصة تعتمد اسم المستخدم والغرفة فقط؛ لا يوجد تسجيل دخول أو تحقق هوية، لذا ليست مناسبة للخصوصية الحقيقية.
- تاريخ الرسائل العامة محفوظ على الخادم، لكن واجهة العميل لا تعرض بعد سجل المحادثات الخاصة القديم تلقائياً عند فتحها.
- حذف الملفات وإدارة المستخدمين غير متوفرين بعد.
